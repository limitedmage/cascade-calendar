# Cascade Ride Calendar privacy policy

Last updated: October 31, 2026

Cascade Ride Calendar is an unofficial Chrome extension that adds a calendar to Cascade Bicycle Club's ride search.

## Information the extension handles

On Cascade's ride search page, the extension reads public ride listings, including titles, dates, times, status, pace, distances, locations, and ride links. It reads the page's search and filter selections to request matching rides and follow results pages. This website content and form information are used only to display the calendar.

The extension stores the list/calendar view preference in the page's session storage for the current browser tab. Completed calendar results are temporarily cached in memory and reused for up to 60 seconds. It also reads Dark Reader's page theme attribute to select compatible colors.

## Network requests and sharing

The extension requests ride search pages from `https://cascade.org` over HTTPS. These requests contain the search and filter parameters needed to retrieve matching rides. Like normal visits to Cascade, they expose the request and normal connection information to Cascade and may include existing Cascade session cookies under the browser's rules. The extension does not read cookie values, passwords, or account information.

The extension does not operate a developer server, use analytics or advertising, or send this information to the developer or other services. Data is not sold, used for advertising, or shared with data brokers. Website content and filter selections are not sent to any service other than Cascade to provide the requested ride search.

Cascade's handling of requests is governed by its own privacy policy.

## Storage and removal

The view preference lasts for the page's browser-tab session and can be changed with the view toggle. Temporary in-memory data is discarded when the page unloads. The extension does not sync data across devices or maintain a browsing-history log.

Closing the tab clears the normal tab session. Browser session restoration can retain session storage; clearing Cascade's site data removes the saved preference. Uninstalling the extension stops it from running but does not itself clear Cascade's site storage.

## Limited use

Information handled by the extension is used only to provide its single purpose: a filterable ride calendar on Cascade's ride search page. Its use of information complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

## Contact and changes

Questions or concerns can be submitted through the [project's issue tracker](https://github.com/limitedmage/cascade-calendar/issues). Do not include personal information in a public issue.

Material changes to these practices will be documented in this policy.
